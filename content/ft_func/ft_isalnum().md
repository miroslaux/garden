```
#include <ctype.h>
int ft_isalnum(int c);
```
DESCRIPTION:	
`checks for an alphanumeric character;`

It is equivalent to ([[isalpha()]] || [[isdigit()]]).
 
RETURN VALUE:
The values returned are nonzero if the character `c` falls into the tested class, and zero if not.
